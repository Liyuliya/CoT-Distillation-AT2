# Teacher-to-Student Chain-of-Thought Distillation

This project trains student language models on reasoning traces generated by teacher models. It compares standard cross-entropy training with a weighted loss and reports student accuracy by dataset and seed.

- [Experiment notebook](notebooks/main.ipynb) contains training, evaluation, and plotting code.
- [Evaluation results](results/) contain JSON summaries by dataset and seed.
- [Figures](figures/) show the accuracy comparison.

## Related work

[Chen et al. (2025), *Unveiling the Key Factors for Distilling Chain-of-Thought Reasoning*](https://aclanthology.org/2025.findings-acl.782/) study how teacher models and reasoning traces affect distillation into smaller student models. Their code and datasets are available in the [Distilling-CoT-Reasoning repository](https://github.com/EIT-NLP/Distilling-CoT-Reasoning).
